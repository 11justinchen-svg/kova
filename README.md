# Kova

Editorial storefront for the Kova clothing brand, built with React, Vite, and Tailwind CSS.

## Local development

```sh
corepack enable
pnpm install
pnpm dev
```

## Production build

```sh
pnpm build
pnpm preview
```

## Deployment

Merges to `main` deploy automatically to GitHub Pages through the workflow in `.github/workflows/deploy.yml`.
